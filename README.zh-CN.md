# Film Desk

[English](README.md) · [相机支持](SUPPORTED_CAMERAS.zh-CN.md) · [安装与首次打开](INSTALL.zh-CN.md) · [下载](https://github.com/Tia-Lin/film-desk/releases/latest)

一款离线 Mac 应用，将相机翻拍的胶片负片转换为正片 JPEG。原始 RAW 文件不会被修改，照片不会上传。

下载版适用于 Apple Silicon Mac，要求 macOS 26 或更高版本。将 Film Desk.app 复制到“应用程序”。更新时在原位置替换已有副本，避免出现两个应用。无需 Python、DaVinci Resolve 或网络连接。应用采用本地签名，没有 Developer ID 签名，也尚未经过 Apple 公证。

## 语言

在菜单 **Language / 语言** 中选择 **English** 或 **简体中文**，立即切换，下次启动会记住选择。初次启动根据系统语言选择中文或英文。切换语言保留照片调整、裁切、文件名和导出完成状态。应用按钮、提示、指南及常规消息支持两种语言；macOS 原生文件选择窗口遵循系统语言，底层解码器或系统错误详情可能保留原文。

## 转换一卷胶片

1. **打开文件夹…**：选择存放相机 RAW 翻拍照片的文件夹，自动生成缩略图。
2. 选中同卷已冲洗、未曝光的空白胶片照片，点击 **设为空白参考**。它用于测量片基颜色，并排除在导出之外。
3. 选择照片，为整卷选择 **彩色** 或 **黑白**，先观察自动转换结果。
4. 按需调整亮度、对比度、色彩强度或暖色。**平衡色彩** 会显示取样框，将整个框放在已知白色或灰色物体内再点击。程序使用框内各通道的中位数；避免彩色物体及过曝高光。框随鼠标移动、随预览缩放，在图像边缘裁切，导出时不会出现。
5. **裁切照片**：拖出单个胶片画面的范围，再点击完成裁切。旋转按钮顺时针旋转 90°。滚轮缩放，拖动平移，“适合窗口”显示全图。
6. **导出 JPEG…**：确认目标目录。文件保留 RAW 的基本文件名、完整裁切分辨率，嵌入 sRGB 配置文件，默认质量 95。已有 JPEG 会跳过；修改后再次导出请使用新的文件夹。

“应用调整到整卷”复制当前照片的色彩和亮度设置，保留各照片裁切。“重置调整”保留裁切、方向和彩色/黑白模式。支持撤销和重做。

## 保存和启动

编辑自动保存，也可通过文件菜单保存命名的 `.filmdesk` 会话。

- 未完成、取消或失败的导出：下次自动恢复。
- 每张选中照片均已确认导出：下次进入新卷的起始界面；“重新打开上一卷”仍可恢复编辑。
- 导出后修改颜色或裁切：再次视为未完成。浏览照片及打开帮助不会改变完成状态。
- 原文件夹不可用：保留编辑，提示继续上次会话并定位目录。

只有与当前设置及已确认文件校验值匹配的已有 JPEG 才计入完成。跳过未经确认的文件不会让会话变成完成。旧版本会话在一次新导出确认前按未完成处理；新卷起始界面不会删除旧会话。

## 默认色彩如何工作

程序以固定、线性的方式解码 RAW，不使用拍摄时的白平衡或自动增亮。利用空白参考去除片基颜色，再从照片估计通道响应，反转负片并调整色调，最后转为带 sRGB 配置的 JPEG。默认色彩来自这套通用转换，不是某款胶片的实测专用曲线。胶片名称及灯光色温输入因为不改变结果，已从界面删除。彩色和黑白模式会实际改变输出。

## 翻拍胶片

应用内 **帮助 → 如何翻拍胶片…** 提供离线指南。以 Sony A7 IV 为例，可从 RAW、手动曝光、ISO 100、f/8、手动对焦及固定 5500 K 灯光开始。调整快门，使透明片基有足够信号且任一通道不过曝。保持胶片平整、相机与胶片平行、照明均匀。

相机白平衡影响机内预览/JPEG，Film Desk 不将其用于 RAW 解码。固定 5500 K 可让拍摄预览一致，但灯具的实际光谱、稳定性和均匀性仍影响结果；同样的色温标称不代表相同光谱。空白参考不能替代空间平场或完整光谱校准。

在相同灯光、扩散板和夹具下，最好用相同曝光拍摄同卷已冲洗、未曝光的胶片。换卷或改变灯光时重新拍摄参考。每个 RAW 拍摄一个画面，包括半格胶片；程序不会自动拆分两个画面，也不会根据胶片物理尺寸裁切。

进一步阅读：[翻拍设置](https://www.negativelabpro.com/guide/scanning/)、[灯光光谱](https://jackw01.github.io/scanlight/)、[Sony A7 IV 感光度](https://helpguide.sony.net/ilc/2110/v1/en/contents/TP1000640844.html)。

## 曝光反馈

程序会提示整个 RAW 扫描中的传感器过曝。胶片外的亮灯区域也可能触发提示，所以请检查实际胶片范围；若胶片区域过曝，减少翻拍曝光（例如缩短快门时间）后重新拍摄。高级设置中的“损失细节提示”显示转换后正片的高光/暗部裁切，可先调整亮度或色调，不应直接当作 RAW 损坏的证据。这些检查无法可靠判断原始胶片拍摄是否欠曝或过曝：胶片种类、冲洗、场景和翻拍曝光都会影响结果。目前没有针对原始照片的经过校准的欠曝评分或建议补偿档数。

## 高级设置

默认折叠，可按需使用绿/品红、阴影、高光及胶片响应调节；整卷响应匹配；水平翻转；恢复自动裁切或复制裁切；刷新缩略图；损失细节提示；保存/载入自定义调整；替换或移除空白参考。

保存的调整名称代表真实参数，不代表实测胶片配置。它不包含裁切、方向及取样中性平衡。整卷匹配会让相似画面共享一个响应；自动模式则分别估计。曝光差异可通过快门、ISO 和光圈元数据归一化，但灯光变化和不均匀照明不能自动补偿。

灰尘、划痕和颗粒会保留，缺失内容不会重建。局部画面和破损胶片边缘可能需要手动裁切。请保留原始 RAW。

## 相机支持

底层使用 rawpy 0.27.1 / LibRaw 0.22.1。Sony A7 IV ARW 已通过真实胶片扫描验证；其他格式能否使用取决于相机型号及 RAW 模式，不能仅由扩展名保证。完整列表和限制见 [相机支持](SUPPORTED_CAMERAS.zh-CN.md)，或应用内帮助菜单。

## 源码和开发

`source/` 采用 MIT 许可证，依赖许可见 `licenses/` 和 `THIRD-PARTY-NOTICES.txt`。应用无账号、上传、遥测、订阅或网络请求。

Apple Silicon Mac 上使用 Python 3.14，在 `source/` 目录执行：

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python app.py
FILMDESK_LANGUAGE=en QT_QPA_PLATFORM=offscreen .venv/bin/python -m unittest discover -p 'test_*.py'
.venv/bin/python -m PyInstaller --noconfirm FilmDesk.spec
```

`FILMDESK_LANGUAGE=en` 或 `zh_CN` 可用于开发时强制语言。常规测试涵盖转换、裁切、取样、导出、会话完成与语言切换。可选真实 RAW 工作流测试需要开发用的 34 帧测试卷，仅写入临时目录；参见英文 README。打包需要 Apple 命令行开发工具，包含两种语言的指南、相机支持说明和依赖许可。允许替换兼容 LGPL 库、重新构建/签名，并按照所附许可证为调试库修改进行逆向工程。
